# PetVida — Projeto de Desenvolvimento Web

Projeto acadêmico desenvolvido para a PUCRS,
utilizando HTML5.

## Objetivo geral

Desenvolver um sistema web informativo para um pet shop fictício chamado PetVida, utilizando a linguagem HTML5, com o objetivo de apresentar produtos, serviços e informações de contato de maneira organizada e acessível aos usuários.

## Objetivos específicos

- Criar páginas HTML para apresentar as informações do PetVida.
- Desenvolver um menu de navegação que permita acessar as diferentes páginas do site.
- Organizar os produtos em categorias, incluindo alimentação, brinquedos e higiene.
- Apresentar os serviços oferecidos pelo pet shop, incluindo descrições, preços e disponibilidade de tele-busca.
- Criar um formulário de contato com campos para nome, e-mail e mensagem.
- Utilizar elementos semânticos do HTML5 para organizar o conteúdo das páginas.

## Metas do projeto

1. Desenvolver quatro páginas HTML: Início, Produtos, Serviços e Contato.
2. Apresentar seis produtos distribuídos em três categorias, contendo imagens, descrições e preços.
3. Disponibilizar informações sobre três serviços oferecidos pelo pet shop.
4. Implementar um formulário de contato com validação dos campos obrigatórios.
5. Padronizar o cabeçalho, o menu de navegação e o rodapé em todas as páginas.
6. Verificar o funcionamento dos links, o carregamento das imagens e a estrutura HTML antes da entrega.
